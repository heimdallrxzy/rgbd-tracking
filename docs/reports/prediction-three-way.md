# normal1 运动预测三方对照

## 对照组

本次按用户指出的三方方案重新比较，全部来自同一 normal1 bag，并用同一编译版本、FIFO32 容量和并行 Tracking/LocalMapping：

1. `baseline_1x`：1x 播放，ORB-SLAM3 原始运动模型预测。
2. `time_aware_1x`：1x 播放，按当前/上一处理帧源时间间隔缩放 SE(3) 运动增量，比例限制在 `[0.5, 2.0]`。
3. `baseline_025x`：0.25x 播放，原始运动模型预测，作为慢放参照。

每组各运行 3 次，组间顺序轮换。重试、同帧恢复、过载降载和低照度适配均关闭；每次重新启动 SLAM。逐帧日志记录输入间隔、预测比例、匹配/优化内点、跟踪状态和关键帧决策。0.25x 是端到端慢放参照，并非固定地图状态下的算法对照。

本次 1x 原始预测 OK 比例均值约 90.76%；时间感知预测约 88.21%，其中一次回放显著偏低。0.25x 三次中两次全程 OK、一次为 89.06%。因此，**本轮没有证据表明时间间隔缩放优于原始预测；慢放在两次重复中表现更好，但慢放结果本身也出现一次明显失跟。**这些是三次回放的描述性结果，不足以形成概率结论。

平均单帧处理耗时：原始预测 1x 三次约 35.2–36.1 ms；时间感知预测 1x 约 34.7–36.6 ms；原始预测 0.25x 约 44.8–46.2 ms。0.25x 没有队列丢帧，但耗时和慢放节奏不同，且 LocalMapping 得到更多后台处理时间。

## 间隔突变帧对照

1x 两组按同一重复编号对齐，并要求目标帧和它的前一处理帧源时间戳都相同，以尽量对齐运动模型的输入帧对。每轮有 668–686 个这样的共同帧，但当前处理间隔达到 50 ms 的样本只有 8–12 个。时间感知与原始预测在这些长间隔帧上的运动模型内点差（时间感知减基线）中位数分别为 `+6`、`-5`、`+7`；对应跟踪状态分别有 2、7、1 帧发生分叉。收益方向不一致。

两次 0.25x 回放 832 对图像全部处理、没有队列丢帧，处理间隔约为源相机帧周期；但其地图演化速度、关键帧历史和 LocalMapping 调度都不同于 1x。它能说明慢放端到端运行表现，不能单独证明改善来自运动预测或仅来自“补回帧”。

## 结论和边界

- 用户所说的三方比较已完成。就当前数据，时间感知预测没有稳定降低失跟；不建议默认开启。
- 0.25x 两次成功、一次明显失跟，说明慢放有潜在收益，但仍受并行地图构建时序和重复运行差异影响。
- 1x 两组即使当前帧与前序处理帧相同，并行 LocalMapping 的地图版本仍未固定；长间隔严格配对样本也只有个位数到十余个。因此本实验不能把某次状态分叉唯一归因于预测缩放。
- 下一步需要针对长间隔/急转弯片段构造可重复输入，并记录预测位姿、投影窗口命中、优化前后内点及局部地图版本。慢放参照应继续保留，但不能把它当成固定算法输入条件。
- 数据集没有独立轨迹真值，本报告只比较跟踪状态、输入丢帧和处理耗时，不声称轨迹精度提升。
